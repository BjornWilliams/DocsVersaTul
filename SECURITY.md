# Security policy

Do not disclose suspected vulnerabilities in public GitHub issues, discussions,
pull requests, commits, or sample data.

## Private disclosure

If GitHub presents a private vulnerability report form for this repository,
use [Report a vulnerability privately](https://github.com/BjornWilliams/DocsVersaTul/security/advisories/new).
If the private form is unavailable, open the affected package from the
[VersaTul NuGet profile](https://www.nuget.org/profiles/bwiliams256) and use
**Contact owners** to request a private disclosure channel. Do not include
vulnerability details in that initial request; share them only after a
maintainer confirms the reply channel is private.

For a confirmed private channel, include the affected package and version,
target framework, impact, a minimal reproduction, and any known mitigation.
Do not send credentials, customer data, or unrelated private application data.

The DocsVersaTul repository owner and maintainers review incoming reports.
There is no guaranteed response or remediation timeline.
