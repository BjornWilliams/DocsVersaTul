Repository Access
=================

The VersaTul code repository is hosted in Azure Repos:
`VersaTul repository <https://technojam.visualstudio.com/VersaTul/_git/VersaTul>`_.

The repository URL exists, but anonymous access has not been verified. Azure
organization membership or sign-in may be required. The public
`DocsVersaTul repository <https://github.com/BjornWilliams/DocsVersaTul>`_
contains the documentation and sample-validation workflow; it is not a public
mirror of the library source.

Do not interpret a NuGet package's Source Link metadata as a promise that the
code repository is anonymously browsable. Use the package's NuGet page for the
published package and its symbols.
